## Section 02Shared layout

  * Cream background, no cards, no icons, no images, no CTAs except a single "Contact us" text link where the source page has one.
  * Eyebrow → H1 → "Last updated [date]" in 13px ink 500 → body in one 680px column.
  * Sub-headings in Jost 600 at 19px; body Hanken Grotesk 16px at 1.68 leading; lists with plain bullets.
  * Linked from the footer only — never in the top navigation.
  * Excluded from the newsletter, from search-engine priority, and from any promotional link.
